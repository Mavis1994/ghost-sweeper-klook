# KLOOK Ghost Sweeper · 万圣幽灵扫雷

## 运行与部署

直接双击 index.html 即可离线游玩，无需安装依赖。保留 index.html、style.css、engine.js、app.js 在同一目录。

部署时，将本目录文件上传至任意静态网页托管平台，确保 index.html 位于发布目录根部。不需要构建命令、后端、数据库或密钥。请一并上传 assets 文件夹。所有资源采用相对路径，支持放在网站子目录。

部署成功后，将生成的 HTTPS 网页地址填入 Lark 活动消息卡片按钮链接，按钮文案设为 KLOOK Ghost Sweeper。用户打开链接后进入复古桌面欢迎窗口，点击 START 开始。此交付未发布线上地址，也未发送 Lark 卡片。

## 玩法

- 12 × 12 棋盘，20 只幽灵，共 124 个安全格。
- START 准备新局，第一次有效翻格开始计时。计时为正向计时，没有倒计时失败限制。
- 首次翻开的格子及其周围最多 8 格均无幽灵。
- 数字表示相邻 8 格的幽灵数量；空白区域自动展开。
- 点击翻格，鼠标右键或触屏长按 450 毫秒插旗/取消旗帜。手机也可开启“插旗模式”，再点击格子。
- 插旗不会自动翻格，插错旗需要取消后才能翻开；无需将幽灵全部插旗即可通关。
- 踩到幽灵立即结束并显示 RETRY；翻开所有安全格后显示开心幽灵和“恭喜你！所有124个安全格子已翻开，用时xx秒。”。OK 进入工号登记界面，下方 Play Again 文字按钮开始新局；失败显示沮丧幽灵及 “Oops! You bumped into a ghost!”。
- New game 或面板幽灵按钮会直接重开，清空当前进度。
- Help / Readme.txt 查看说明；最小化后点击任务栏恢复。
- 键盘可用 Tab 选择格子、方向键移动、Enter/空格翻格、F 插旗。

## 文件

- index.html：桌面、棋盘与弹窗结构，内置像素图标。
- style.css：响应式紫橙复古视觉。
- engine.js：独立扫雷模型。
- app.js：鼠标、触屏、键盘、计时及结果交互。
- tests.cjs：可用 Node.js 运行的核心逻辑回归测试（node tests.cjs）。

## 通关登记接入（待确定收集目标）

通关后点击 OK 进入工号填写界面，也可关闭后点击棋盘下方“登记通关”返回。工号保持为文本，不丢失前导零。Play Again 开始新一局。手机棋盘按屏幕宽度自适应，完整显示 12 列，不需要横向滑动。支持点击翻格、长按 450ms 插旗和插旗模式。

当前 config.js 的 registrationEndpoint 为空，因此不会发送或假装保存工号。确定收集目标后再配置。若采用自有接口，该接口需要接收 POST JSON：employeeId、runId、elapsedSeconds、boardSize、ghosts、completedAt。只有 HTTP 成功且返回 {"ok":true} 才显示登记成功。失败或超时可以重试；服务端必须按 runId 幂等保存，防止重试产生重复记录。跨域时需由接口允许游戏域名。

不要在 config.js 写入 Lark 应用密钥或其他凭据；调用多维表格写入接口应通过后端。表单链接方案需按最终链接单独接入，不要把表单页面 URL 填进 registrationEndpoint。当前前端成绩不能作为防作弊认证；如需严格验证员工身份及通关资格，需要服务端验证。
